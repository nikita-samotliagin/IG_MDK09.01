# Конференции.РФ

Портал бронирования помещений для конференций. Участник регистрируется, отправляет заявку, следит за её статусом и оставляет отзыв. Администратор просматривает заявки и меняет статусы.

Для запуска нужны PHP 8.1 или новее и расширения PDO, pdo_sqlite, mbstring.

Из папки `konf` выполните:

```sh
php database/seed.php
php -S 127.0.0.1:8000 -t public public/index.php
```

Откройте http://127.0.0.1:8000.

Команда seed.php создаёт демонстрационные данные. Повторный запуск их не дублирует. Без этой команды база и администратор создаются при первом открытии сайта.

Дата заявки вводится в формате `ДД.ММ.ГГГГ ЧЧ:ММ`, даты фильтра администратора — `ДД.ММ.ГГГГ`. Номер телефона можно ввести как `8(916)123-45-67` или `89161234567`.

Код страниц находится в `views`, обработчики — в `src/Controller`, запросы к БД — в `src/Repo`, стили и JavaScript — в `public/assets`.

Для MySQL выполните `database/schema_mysql.sql` и задайте переменные KONF_DSN, KONF_DB_USER, KONF_DB_PASS перед запуском. Для SQLite дополнительная настройка не нужна.
